# TimeAlign

A lightweight, frontend-only tool for scheduling meetings across multiple time zones. No installation, no backend, no data stored anywhere.

**[Open TimeAlign →](https://n0t0ri0vs.github.io/time-align/time-align.html)**

## What it does

- Find a meeting slot that works for up to 4 participants across different time zones
- Mark busy slots on a weekly calendar grid and get ranked suggestions
- Convert a time from any timezone to your local time instantly
- Copy formatted meeting times ready to paste into Teams or Outlook

## Usage

Open the link above directly in any browser. No install required. All processing happens client-side — nothing leaves your browser.

To run locally: download `time-align.html` and open it in a browser.

## Stack

Single HTML file. Vanilla JS + CSS. [Luxon](https://moment.github.io/luxon/) for timezone handling (loaded via CDN with SRI integrity check).
